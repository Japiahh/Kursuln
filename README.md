# Kursuln

### Deskripsi 
KursusIn adalah aplikasi untuk mengelola registrasi peserta pada berbagai program pelatihan digital. Data utama yang digunakan adalah data peserta, data katalog kursus, dan data bidang minat. Pengguna aplikasi adalah admin pendaftaran atau koordinator kursus.
Fitur-fitur: 
1.	Pengaturan Perserta
a.	Tambah Peserta
b.	Edit Peserta
c.	Hapus Peserta
2.	Cari Data Perserta
3.	Lihat Peserta
4.	Ringkasan Statistik
