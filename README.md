### Deskripsi 
KursusIn adalah aplikasi untuk mengelola registrasi peserta pada berbagai program pelatihan digital. Data utama yang digunakan adalah data peserta, data katalog kursus, dan data bidang minat. Pengguna aplikasi adalah admin pendaftaran atau koordinator kursus.
Fitur-fitur: 
1.	Pengaturan Perserta
a.	Tambah Peserta
b.	Edit Peserta
c.	Hapus Peserta
2.	Cari Data Perserta
3.	Lihat Peserta
4.	Ringkasan Statistik

### Tantangan dan Solusi
•	Tantangan; output daftar yang berulang kali digunakan, input katalog manual yang rawan typo.
•	Solusi; membuat prosedur khusus yang dapat dipanggil untuk efektifitas kode, fitur compiler yang menerjemahkan input pengguna dari angka (integer) ke daftar katalog dan bidang minat(string).

### Kesimpulan dan Rekomendasi
Kursusln dikembangkan dengan fitur yang mempermudah dalam pengimputan data. Pengembangan selanjutnya Adalah system navigasi yang memungkinkan pengguna melompat dari tab asal ke tab yang lain.
